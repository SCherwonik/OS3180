# Extra Context Sources

Generated by 08_extra_context.py.

## outputs/context_extra.csv

| Column | Source | Notes |
|---|---|---|
| `fatalities` | BTS NTS Table 2-17 (FARS-based) | 5-year steps 1960-1985, annual 1990+; 30-day death definition |
| `bts_vmt_million_miles` | same table (FHWA) | matches FRED VMT closely; kept separate for rate consistency |
| `fatality_rate_per_100m_vmt` | same table, BTS-calculated | THE safety series; do not recompute from mixed sources |
| `auto_sales_millions_saar` | BEA via FRED DAUTOSAAR+FAUTOSAAR | calendar-year mean of monthly SAAR, 1967+ |
| `lt_sales_millions_saar` | BEA via FRED DLTRUCKSSAAR+FLTRUCKSSAAR | same |
| `lt_share_of_sales` | derived | light-truck share of light-vehicle SALES; compare with production share but note sales != production and calendar != model year |

## external/events_timeline.csv

Curated documented events (regulation/scandal/market) with a source citation per row. Annotation layer only; not measurements. Regenerated by this script on every run.

Retrieval note: bts.gov and nhtsa.gov block command-line clients (403). The BTS workbook was retrieved through the user's browser on 2026-08-14. The NHTSA FARS API was abandoned for this reason; BTS Table 2-17 carries the same FARS-based fatality series.
