# Insurance Data Prep and Automation-Score Audit

Generated by 16_insurance_prep.py from Phil's workbook (Insurance Project Dataset - 2026.09.01.xlsx).

## Cleaning

- Rows kept: 11,313
- rows with empty vehicle/year dropped: 0
- IIHS loss values are relative deviations from the all-vehicle average for the window (-0.30 = 30% better than average), per the IIHS/HLDI losses-by-make-and-model publication.

## Automated audit of the Grok-derived automation scores

The workbook's 'Automation Score Supporting Links' section contains zero links; scores are uncited AI output. Automated checks:

1. **Lookup consistency.** 738 lookup rows, 1 duplicated keys, 0 with conflicting scores.
2. **Window-invariance.** 540 of 2369 vehicles change score across windows (examples: ['Acura ILX', 'Acura MDX 4dr 4WD', 'Acura RDX 4dr', 'Acura RDX 4dr 4WD', 'Acura RLX 4dr', 'Acura TLX 4dr 4WD', 'Aston Martin Vantage V8 2dr', 'Audi A3 4dr 4WD', 'Audi A3 convertible 4WD', 'Audi A4 4dr']).
3. **EV plausibility.** 658 EV-pattern rows; EVs scored 'Basic': none. Every US-market EV ships standard ADAS, so any entry here is a suspect label.
4. **Tesla check.** 19 Tesla rows with windows ending 2020+; scored below 3: none.

**Human-verification worksheet**: outputs/automation_score_audit_sample.csv (30 randomly sampled vehicles, seeded) with blank columns for the verified score, the source consulted, and agree/disagree. Verify against manufacturer equipment pages or IIHS ratings pages and report the agreement rate on the data-sources slide.

## Catalog join

- Match rate: 92.2% of rows matched a fueleconomy.gov (make, base model); attributes (`cat_comb08_mpg`, `cat_displacement_l`, `cat_cylinders`, `cat_is_ev`) averaged over the window years.
- Matching tries the full trim string, then progressively drops trailing tokens ('civic si hatchback' -> 'civic si' -> 'civic'), so a trim can inherit its base model's attributes; that is the price of the match rate and is acceptable for MPG/displacement controls, not for anything trim-specific.
- Unmatched rows keep null attributes and stay in the file; the model stage decides handling.
